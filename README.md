# Phulesh Singh Portfolio

A responsive personal portfolio website built for static hosting on GitHub Pages.

## Features
- Responsive design
- Mobile navigation menu
- Light and dark theme
- Smooth scrolling and reveal animations
- Education, skills, project, training and certification sections
- Direct contact links
- No build process required

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Folder Structure
```text
portfolio/
├── index.html
├── css/style.css
├── js/script.js
└── assets/
    ├── images/
    └── documents/
```

## Add Your Profile Image
Replace `assets/images/profile-placeholder.svg` with your preferred image, or update the image path in `index.html`.

## Add Project Images
Replace `assets/images/project-placeholder.svg` or add new images inside `assets/images/`.

## Add Your Resume
Place your actual resume at:
`assets/documents/resume.pdf`

The Download Resume button is already configured to use this path.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this project.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub Pages to publish the site.
