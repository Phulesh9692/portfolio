# Phulesh Singh – Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Publish on GitHub Pages
1. Create a repository (e.g. `Phulesh9692.github.io` or `portfolio`).
2. Upload all files from this folder (keep the folder structure).
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
4. Your site appears at the URL shown on that page.

## Update content
- Text, projects, skills: `index.html` (comments mark each section).
- Colours and fonts: top of `css/style.css`.
- Photo: replace `assets/images/profile.jpg`.
- Resume: replace `assets/documents/resume.pdf`.
- Project image: add a file in `assets/images/` and replace the "Project image" placeholder div in `index.html`.
- Training period: replace `[add period]` in the Training section.
